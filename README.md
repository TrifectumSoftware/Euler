Since i've started modding, i've always been pretty annoyed by having to port my mods individually to each version. In early 2026 I worked on a project called Fulcrum which failed horribly at making a cross-platform library, but that was a different time.
Euler is a mod that intends to fix that in the best way i can think of, by abstracting item registration, netcode, and almost everything except render and mixin for my own use. It makes moddev much more convenient, allowing me to target all versions for more generic features and mods without having to haphazardly port each feature.

- 1.12.2 Forge
- 1.20.1 Forge/Fabric
- 1.21.1 NeoForge/Fabric
